#  Scripts_en_Cpp

Bienvenido a **Scripts_en_Cpp**, una colección de ejercicios básicos en **C++**, perfecta para practicar la sintaxis, lógica y fundamentos del lenguaje.

---

##  Contenido del repositorio

Este repositorio incluye una serie de archivos como:

- `Ejercicio1.cpp`, `Ejercicio2.cpp`, ..., hasta `Ejercicio33.cpp`.

Cada uno contiene un ejemplo independiente desarrollado en C++, ideal para comprender:

- Sintaxis básica (variables, tipos de datos)
- Estructuras de control (`if`, `for`, `while`)
- Funciones y modularidad
- Algoritmos sencillos y problemas clásicos
- Operaciones con colecciones básicas (arrays, vectores)

---

##  ¿Cómo usar estos ejercicios?

1. Asegúrate de tener un compilador de C++ instalado (por ejemplo, g++, clang++, o similar).

2. Clona o descarga el repositorio:
   ```bash
   git clone https://github.com/UrbanoTrejoOrlando/Scripts_en_Cpp.git
   cd Scripts_en_Cpp

3. Para compilar y ejecutar un ejercicio:
   ```bash
   g++ EjercicioX.cpp -o EjercicioX && ./EjercicioX
